# Домашнее задание №2

### Как сдавать решения?

1. Склонировать репозиторий

2. Установить [uv](https://github.com/astral-sh/uv):

```bash
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh
```

1. Установить Python с помощью uv: `uv python install 3.13.0`

После запуска `uv run python` все зависимости будут установлены все дополнительные зависимости.

4. Сделать ветку `dev`: `git checkout -b dev`. Решать задания нужно будет именно в этой ветке. Для каждой задачи подготовлен соответствующий файлик в папке `solution`.

5. Как только вы готовы отправить решение, то необходимо открыть Pull Request в ветку `main` в вашем репозитории и добавить вашего преподавателя в Reviewers. Важно называть свои Pull Request-ы в формате `HW2. Иванов Иван`. Это помогает преподавателям быстрее ориентироваться среди ваших решений. Pull Request-ы, которые имеют другое название, могут быть проигнорированы.


### Как локально запустить тесты?

1. Для того чтобы запустить тесты на задачу `N` нужно выполнить команду `uv run pytest test/test_taskN.py` из корня репозитория и команду `uv run pytest .`, если вы хотите запустить все тесты. Также вам может помочь флажок `-s`, если вы хотите видеть отладочный вывод в тестах.

2. Также может быть полезно запустить линтеры и форматтер на вашем коде с помощью команды `make fmt lint`.

#### 4. Повторная попытка (2 балла)

Напишите декоратор `retry`, который будет запускать функцию заново, если при её вызове произошла какая-либо ошибка из переданного списка ошибок.

Декоратор должен принимать на вход тип ошибки (или кортеж из типов ошибок), а также ограничение на максимальное количество повторных вызовов функции. Если после максимального количества попыток функция продолжает возвращать ошибку, то необходимо выбросить эту ошибку, а не делать очередной вызов.

```python
call_count = 0

@retry(ValueError, max_attempt=10)
def foo():
  nonlocal call_count
  call_count += 1

  if call_count < 9:
    raise ValueError

  return 42

print(foo())  # 42

# Но если max_attempt установить, например, в 5, вызов `foo()` должен выбрасывать `ValueError`.
```
