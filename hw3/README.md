### Как сдавать решения?

1. Склонировать репозиторий

2. Установить [uv](https://github.com/astral-sh/uv):

```bash
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh
```

1. Установить Python с помощью uv: `uv python install 3.13.0`

После запуска `uv run python` все зависимости будут установлены все дополнительные зависимости.

4. Сделать ветку `dev`: `git checkout -b dev`. Решать задания нужно будет именно в этой ветке. Для каждой задачи подготовлен соответствующий файлик в папке `solution`.

5. Как только вы готовы отправить решение, то необходимо открыть Pull Request в ветку `main` в вашем репозитории и добавить вашего преподавателя в Reviewers. Важно называть свои Pull Request-ы в формате `HW2. Иванов Иван`. Это помогает преподавателям быстрее ориентироваться среди ваших решений. Pull Request-ы, которые имеют другое название, могут быть проигнорированы.

Реализуйте класс, представляющий полиномы над полем вещественных чисел. 

Определите операции:
- сложение,
- вычитание,
- умножение на скаляр,
- умножение,
- `__str__` и `__repr__` (заодно напишите в чём их принципиальное отличие),

Также должны быть реализованы "отраженные" операции, а также операции присваивания:
```python
poly1 = Poly([1, 2, 3])
poly2 = Poly([1, 2, 3])

poly1 += poly2

``` 

#### 2. Implicit (1 балл)

Убедитесь, что класс это тоже объект:

```python
class A:
    pass

print(id(A))
# 140199780173328

print(dir(A))
# ...
```

Декораторы также могут быть применены к классу. Как и в случае с функциями декоратор должен возвращать новый 
(или такой же) класс:

```python
def replace_repr(cls):
    cls.__repr__ = lambda self: f"object of cls {cls.__name__}"
    return cls

@replace_repr
class A:
    pass

print(A())
# object of cls A
```

Напишите декоратор `implicit`. Если приписать его к классу, то при обращении к необъявленному полю экземпляра этого
класса будет возвращаться значение из переданного в `implicit` объекта (или объектов, если передали кортеж), 
Вам поможет магически метод [`__getattr__`](https://rszalski.github.io/magicmethods/#access).

```python
class E:
    e = 1

@implicit(E())
class A:
    pass
    
a = A()
print(a.e + 589)  # Вывод: 590
```

#### 3. Heap + Iterator (3 балла)

Реализуйте класс `Heap` - минимальную бинарную кучу на основе списка.

Определите методы:
- `push(value)` - вставка элемента (heapify-up),
- `pop()` - извлечение минимума (heapify-down),
- `__len__`, `__repr__`.

Также реализуйте итератор `HeapIterator`. Метод `__iter__` класса `Heap` должен возвращать итератор, который выдаёт элементы в порядке возрастания. Итератор должен работать на **копии** данных и не изменять исходную кучу.

```python
h = Heap()
for x in [5, 2, 8, 1]:
    h.push(x)

print(list(h))  # [1, 2, 5, 8]
print(len(h))   # 4 - куча не изменилась
```
