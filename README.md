# Коллекция домашних заданий по Python

В этом репозитории собраны домашние задания по языку Python, охватывающие широкий спектр тем: от базовых алгоритмов и estructuras данных до асинхронного программирования, веб-разработки на FastAPI и работы с базами данных. Каждое задание представляет собой отдельный проект с собственными тестами и системой автоматической проверки.

---

## Список домашних заданий

### HW1 — Базовые алгоритмы и структуры данных
Простые задачи для освоения синтаксиса Python: работа со списками и строками, словари для построения обратного словаря, умножение и красивый вывод матриц, реализация аналогов утилит `wc`, `nl`, `tail`.  
**Навыки:** списки, строки, словари, файловый ввод-вывод, работа с аргументами командной строки.

### HW2 — Продвинутые функции и декораторы
Функции Фибоначчи с динамическим созданием функций, проблема замыканий в Python, декартово произведение множеств, НОК для произвольного числа аргументов, декораторы `retry` и `calmer` для управления выполнением функций.  
**Навыки:** замыкания, декораторы, произвольное количество аргументов (`*args`, `**kwargs`), работа с временем.

### HW3 — Объектно-ориентированное программирование и итераторы
Класс `Poly` для работы с полиномами с перегрузкой всех арифметических операций, декоратор `implicit` для класса, бинарная куча с итератором для обхода элементов по возрастанию.  
**Навыки:** ООП, перегрузка операторов, магические методы, декораторы классов, структуры данных (куча), итераторы.

### HW4 — Итераторы, генераторы и асинхронность
Итератор для бинарного дерева (in-order обход), генератор для обхода дерева, EventLoop с кооперативной многозадачностью на генераторах, асинхронные функции `gather`, `first_result`, `run_with_timeout`, реализация GETLIST-сервера на asyncio, echo-сервер с подсчётом сообщений, таймаутом и broadcast-рассылкой.  
**Навыки:** итераторы, генераторы (`yield`, `yield from`), `asyncio`, конкурентное программирование, сетевые протоколы.

### HW5 — Mission Control (FastAPI + Open-Meteo)
Веб-приложение на FastAPI для мониторинга погоды на космодромах. Включает Pydantic-модели, асинхронный клиент для Open-Meteo API, логику анализа условий запуска (go/no-go/caution), REST API с обработкой ошибок, веб-дашборд с цветовыми индикаторами.  
**Навыки:** FastAPI, Pydantic, httpx, асинхронные запросы, REST API, Jinja2-шаблоны, работа с внешними API.

### HW6 — Watchlist API (FastAPI + PostgreSQL)
REST API для персонального трекера фильмов. Реализованы жанры, фильмы, пользователи, отзывы (с рейтингом 1–10), закладки (watched/will_watch). Поддержка фильтрации, сортировки, агрегаций (`avg_rating`, `reviews_count`), каскадного удаления. Нагрузочный тест на 100 параллельных запросов.  
**Навыки:** FastAPI, SQLAlchemy ORM (или psycopg2), PostgreSQL, Pydantic, обработка ошибок, производительность.

### Exam — Экзамен по ОМП Модуль 2
Комплексное задание: реализация структуры данных `FixedSizeQueue` на массиве (циклический буфер) с операциями `put`, `get`, `in`, операторами `+` и `+=`, свойством `empty`/`full`, клонированием. Декоратор `trace_if`, менеджер контекста для транзакций, итераторы для очереди с учётом циклического буфера.  
**Навыки:** структуры данных, циклический буфер, декораторы, менеджеры контекста, итераторы.
