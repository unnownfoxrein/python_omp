## Python домашние задания

### HW1 – Базовые алгоритмы и структуры данных
Задачи на работу со списками, строками, словарями, матрицами, а также реализация аналогов утилит `wc`, `nl`, `tail`.  
**Навыки:** списки, строки, словари, файловый ввод-вывод, аргументы командной строки.

### HW2 – Продвинутые функции и декораторы
Динамическое создание функций, замыкания, декораторы `retry` и `calmer`, декартово произведение, НОК для произвольного числа аргументов.  
**Навыки:** замыкания, декораторы, `*args`, `**kwargs`, работа с временем.

### HW3 – ООП и итераторы
Класс `Poly` с перегрузкой операторов, декоратор `implicit` для классов, бинарная куча с итератором.  
**Навыки:** ООП, перегрузка операторов, магические методы, декораторы классов, структуры данных (куча), итераторы.

### HW4 – Итераторы, генераторы и асинхронность
Итератор для дерева, генератор `inorder`, EventLoop на генераторах, асинхронные функции (`gather`, `first_result`, `run_with_timeout`), GETLIST-сервер, echo-сервер с broadcast.  
**Навыки:** итераторы, генераторы (`yield`, `yield from`), `asyncio`, конкурентное программирование, сетевые протоколы.

### HW5 – Mission Control (FastAPI + Open-Meteo)
Веб-приложение для мониторинга погоды на космодромах. Включает Pydantic-модели, асинхронный клиент для Open-Meteo API, анализ условий запуска, REST API, веб-дашборд.  
**Навыки:** FastAPI, Pydantic, httpx, асинхронные запросы, REST API, Jinja2-шаблоны, работа с внешними API.

### HW6 – Watchlist API (FastAPI + PostgreSQL)
REST API для персонального трекера фильмов: жанры, фильмы, пользователи, отзывы, закладки. Поддержка фильтрации, агрегаций, каскадного удаления. Нагрузочный тест на 100 параллельных запросов.  
**Навыки:** FastAPI, SQLAlchemy ORM (или psycopg2), PostgreSQL, Pydantic, обработка ошибок, производительность.

### Exam – Экзамен по ОМП Модуль 2
Структура `FixedSizeQueue` на циклическом буфере с операциями `put`, `get`, `in`, операторами `+`/`+=`, свойствами `empty`/`full`, клонированием. Декоратор `trace_if`, менеджер контекста для транзакций, итераторы для очереди.  
**Навыки:** структуры данных, циклический буфер, декораторы, менеджеры контекста, итераторы.
